（一）传导的总体逻辑链条
房地产风险传导遵循 "销售端 → 开工端 → 施工端 → 竣工端 → 后周期消费端" 的时序链条，且各环节存在明显的滞后周期差异：
销售下滑 → 房企现金流恶化 → 拿地/新开工收缩 → 施工放缓 → 竣工减少 → 后周期消费萎缩

（三）三大传导机制
1. 需求传导（量）：销售下滑 → 新开工收缩 → 上游建材需求萎缩
数据佐证：2026年8月房屋新开工面积累计同比 -24.8%，施工面积 -12.8%，竣工面积 -23.7%
上游水泥产量累计同比 -9.0%、粗钢 -3.1%、平板玻璃 -6.4%
2. 资金/信用传导（金融）：房企暴雷 → 上下游应收账款坏账 → 银行信贷收缩
数据佐证：居民消费性贷款同比 -1.7%（2026Q2），住户经营性贷款同比降至 2.8%
建材企业应收账款减值风险上升（东方雨虹、三棵树等计提减值）
3. 财富效应传导（价）：房价下跌 → 居民资产负债表收缩 → 消费意愿下降
数据佐证：2024Q2实际GDP同比回落0.6pct，最终消费贡献大幅回落1.7pct至2.2pct
城镇居民财富60%为住房，房价下跌直接冲击居民消费能力

四、关键结论
传导时序：销售端最先反应（T0），工程机械/设计（0-2月）→ 钢铁/水泥/玻璃（2-6月）→ 竣工端家电（6-12月）→ 家具/装修（12-24月）
影响程度排序（从高到低）：
最严重：装修装饰（净利增速-475%）、房地产开发（净利率-11.9%）
严重：建材/涂料（资产负债率高达77-89%）、水泥
中等：钢铁、玻璃
相对较轻：白色家电（C端零售缓冲）、家具（存量市场对冲）
核心传导机制：需求传导（量）> 资金信用传导（金融）> 财富效应传导（价）
当前状态（截至2026年8月）：房地产仍处深度调整期，新开工-24.8%、开发投资-19.9%，产业链上游建材、中游开发、下游装修均承压，但白色家电因C端零售和出口对冲相对抗跌。
