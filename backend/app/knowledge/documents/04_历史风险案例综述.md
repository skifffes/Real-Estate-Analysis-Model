# 历史风险案例：日本1990 vs 美国2008 vs 中国恒大2021

## 日本（1990）
广场协议后超低利率催生泡沫，1989-1990年央行连续加息刺破泡沫。六大城市地价累计跌幅超60%。传导路径：货币政策收紧 → 资产价格崩塌 → 银行不良债权 → 企业资产负债表衰退 → 消费与投资长期萎缩。建筑业产出十年下滑约40%，经济陷入"失去的二十年"。教训：房价与信贷深度绑定时，泡沫破裂的产业链冲击具有长期性。

## 美国（2008）
次级贷款+证券化（MBS/CDO）扩张，2004-2006年加息后断供潮爆发。新屋开工从峰值下降约75%，GDP连续四个季度负增长。传导路径：次贷违约 → 结构化产品估值崩塌 → 流动性冻结 → 信贷收缩 → 实体衰退。教训：金融加速器将局部风险放大为系统性危机，产业链中家具、家电等后周期行业受创深重。

## 中国恒大（2021）
"高杠杆+高周转"模式遭遇三道红线，2021年下半年流动性危机公开化。传导路径：融资受限 → 停工与销售下滑 → 上游供应商应收账款风险 → 债券违约 → 金融机构敞口暴露 → 土拍降温传导至地方财政。全国商品房销售面积连续三年负增长。教训：信用风险沿应付账款渠道向上游传导的速度快于价格渠道。

## 海南（1992-1993）
特区预期驱动投机，1993年宏观调控急刹车后烂尾楼遍地，海南发展银行被清算。教训：区域性泡沫成本主要由地方金融体系与建筑业承担。

## 跨案例规律
1. 冲击起点多为"金融条件收紧+销售下滑"的组合
2. 建筑业、建材、金融业在所有案例中均受显著冲击
3. 政策救助的关键时点在流动性危机向偿付危机转化之前
