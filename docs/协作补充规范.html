一、历史案例补充模板（案例库扩充）

1.1 选案建议（不同类型 × 城市能级）

建议覆盖四种类型，每种 1-2 个案例，形成"类型完备"的案例库：

类型 候选城市 建议理由
政策急冻型 深圳（2021 二手房指导价） 政策直接压制交易，量价齐跌的典型
企业暴雷型 郑州（2022 烂尾楼/停贷断供潮） 房企信用风险向居民端、金融端传导
投机崩盘型 温州（2011-2014 炒房团崩盘） 三线城市投机泡沫完整周期
需求透支型 燕郊（环京腰斩） 外溢需求退潮后的极端跌幅

另可选补充：北京（政策组合拳全周期）、杭州（2021 抢人+调控）。

# —— 传导过程 ——

  - 第一步：...

# —— 涉及主体 ——

  - name: 中介机构

  - name: 本地银行
    role: 按揭业务量变化、评估价与指导价差异处理

# —— 量化证据（核心，尽量给数字）——
quantitative_evidence:
  二手房成交量变化: 同比 -60%+（2021年2-3月）
  挂牌价与成交价价差: 约 20%-30%

data_sources: [深圳中原/乐有家研究中心, 国家统计局70城指数, 贝壳研究院]

1.3 优先级说明

  • 量化证据 > 定性描述：传导路径有数字（成交量、跌幅、持续时间）最有价值
  • 政策文件名：如"深房参考价机制"的官方名称，便于知识库精确检索
  • 4-6 个案例即可，宁精勿滥

二、行业指标与财务数据要求（传导机制量化补充）

2.1 覆盖行业

优先级排序（对应系统 13 部门口径）：

优先级 行业 核心指标
P0 房地产 新开工/施工/竣工面积、销售面积与金额、70城/百城价格指数、房企到位资金
P0 建筑 建筑业总产值、PMI 建筑分项
P1 建材 水泥产量与价格、玻璃产量与库存、螺纹钢产量与价格
P1 家电家具 家电零售额、家具零售额、地产后周期销售数据
P2 金融 居民中长期贷款、房企信用债发行与违约、银行房地产不良率

2.2 格式要求（重要）

格式：CSV 或 Excel，长表或宽表均可，但请满足：

  1. 频率：月度优先（季度可接受）；时间跨度至少 2015 至今（覆盖完整上行→下行周期）
  2. 列名规范：列名中包含指标性质关键词，系统自动识别：
  3. 收入/销售/营收/产量 → 收入类
  4. 负债率/资产负债率 → 债务类
  5. 现金流 → 现金流类
  6. 价格/需求 → 市场类
  7. 同比/环比标注：数值请明确是同比%、环比%还是绝对值（列名注明）
  8. 缺失处理：缺失月份留空即可，勿填 0
  9. 来源标注：每个文件注明数据出处（统计局/行业协会/Wind/Choice）

示例列名（可直接套用）：

月份,商品房销售面积同比(%),新开工面积同比(%),水泥产量同比(%),螺纹钢价格同比(%),家电零售额同比(%),居民中长期贷款同比(%)
2021-01,64.3,64.3,10.1,9.8,15.1,31.6
...
