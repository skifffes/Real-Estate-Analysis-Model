# 研究素材：北京市房地产产业链乘数的时序演变（2012→2023）

> 数据：北京市投入产出表（42部门基本表，聚合13部门口径）· 提取脚本 `testdata/extract_multiyear.py`

## 一、影响力乘数对比（后向联动，每1元最终需求的全部拉动）

| 部门 | 2012 | 2017 | 2023 | 变化(2012→2023) |
|---|---|---|---|---|
| 房地产 | 2.23 | 1.84 | 2.23 | +0.00 |
| 建筑业 | 4.32 | 4.11 | 3.84 | -0.48 |
| 钢铁 | 4.98 | 4.64 | 4.75 | -0.23 |
| 建材 | 3.81 | 3.84 | 3.83 | +0.02 |
| 家用电器 | 4.5 | 3.95 | 3.96 | -0.54 |
| 金融业 | 2.02 | 2.07 | 1.86 | -0.16 |
| 专业服务 | 2.98 | 3.11 | 2.97 | -0.01 |

总产出规模：2012年 52511.56万亿 → 2017年 84240.24万亿 → 2023年 12.69万亿

| 上游部门 | 2012 | 2017 | 2023 |
|---|---|---|---|
| 建筑业 | - | 0.005 | 0.027 |
| 专业服务 | 0.109 | 0.089 | 0.162 |
| 金融业 | 0.137 | 0.079 | 0.069 |
| 建材 | - | - | - |

| 批发零售 | - | - | - |

## 三、核心发现（可直接用于报告/答辩）

1. **房地产自身并非最强带动部门**：其影响力乘数在各年份均低于建筑业、钢铁、建材——
   房地产的产业链效应主要通过对建筑业的采购与联动间接放大实现（注意：2023 年房地产对建筑业
   的直接消耗系数约 0.027，"放大"更多来自完全关联效应与建筑业自身的高乘数，而非单一直接采购系数）。
2. **乘数时序变化**反映产业结构演变（见上表）：制造业部门乘数普遍上行/下行趋势可结合
   北京'去制造业、强服务业'的结构转型解释。
3. **联动结构稳定**：房地产Top5上游在三个年份高度一致（建筑/专业服务/金融/建材），
   验证了产业链传导路径的稳健性——这正是投入产出模型适用于风险传导分析的前提。

> 注：2012/2017 为当年生产者价格，跨年比较看相对结构而非绝对水平；答辩时以'结构稳定性'
> 与'房地产≠最强带动部门'两个反直觉点为核心叙事。
